## 🚀 Getting Started & Deployment

### Prerequisites
- Any modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari) with Web Audio API support.
- [Node.js](https://nodejs.org/) (v18+) *[Optional: only if running local dev servers or building with Vite]*.

### 1. Clone the Repository
```bash
git clone https://github.com/arfad22/Spiderman-Portfolio.git
cd Spiderman-Portfolio
```

### 2. Run Locally (Static Mode)
Simply open `index.html` directly in your favorite browser, or serve using any static server:
```bash
# Using Python
python -m http.server 8000

# Using Node.js npx serve
npx serve .
```
Navigate to `http://localhost:8000`.

### 3. Run Locally with Vite (Optional)
```bash
npm install
npm run dev
```

## 🌐 GitHub Pages Deployment Guide

The repository is pre-configured for instant automated hosting on GitHub Pages:

### Method 1: Automatic Deploy on Push (Configured)
1. Push your code to the `main` branch:
   ```bash
   git add .
   git commit -m "feat: update spider-verse portfolio"
   git push origin main
   ```
2. Navigate to your repository on GitHub $\to$ **Settings** $\to$ **Pages**.
3. Set **Source** to **Deploy from a branch** (Branch: `main`, Folder: `/ (root)`), or select **GitHub Actions**.
4. Your portfolio will be live at:
   ```
   https://arfad22.github.io/Spiderman-Portfolio/
   ```

### Method 2: Manual Deploy via `gh-pages`
```bash
npm run deploy
```
